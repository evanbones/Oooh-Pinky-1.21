# Oooh, Pinky Porty!

<a href='https://neoforged.net/'><img alt="neoforge" height="56" src="https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/supported/neoforge_vector.svg"></a>

JerryLu086's [Oooh, Pinky!](https://modrinth.com/mod/oooh-pinky) ported to NeoForge 1.21!

Description from the original modpage:

A simple mod that allows you to create Rose Gold alloy for different usages.

You can either craft new equipment with it or use it to barter with Piglins.

There are the properties of Rose Gold items:

* Mining speed / enchantability slightly above netherite, but lower than gold.
* Durability / defense above iron.
* Piglins won't attack you while wearing any piece of the armor
